*What is a scalar?*.

A **scalar** defines the amount of something in one dimension. They are accompanied by a unit which signifies the dimension in particular. We learn about dimensions as a concept of length (e.g., meters), but a dimension can be generally described as one aspect of a thing.

Each of these dimensions for describing the car has a number followed by the unit, which makes up the **scalar quantity**.

Scalar arithmetic.

Scalar quantities can only be combined (or separated) when the have the same unit. For example, a 50 - min class that ends 10 min early lasts for 50 min - 10 min equals 40 min.

If you were told that the class ended 600 sec early, **you cannot combine (or separate) the quantities directly**. Instead, you must *first* convert to a common unit, then you can proceed as before.

 
50 min - 600 sec equals, 
50 min - [ 600 sec over 1 times 1 min over 60 sec ] equals, 
50 min - 10 min equals 40 min.

*What is a vector?*.

A **vector** combines scalar quantities as a new object that delineates the quantities by their dimension. A unit vector represents a single step along a dimensional axis and is signified using the `hat` (or hat{} ) symbol over the variable for that axis. For example, 1 unit step along the x-axis is represented by x hat, which can be written as ` x hat ` a the text cell in your Jupyter notebook.

*Properties of vectors*.

The **resultant** vector vector R of two vectors vector A and vector B can be determined by the addition of the two vectors as

 
 vector R equals vector A + vector B.
 

When we draw the resultant vector, we place them the tail at the origin and draw to place the head at the final location (i.e., head-to-tail method). In our above example, vector D sub AD was the resultant vector of the vector D sub AC + vector D sub CD.

In general, vectors have similar properties as scalars. We can:

Bullet point. add any number of vectors in any order, where vector addition is **commutative**.

 vector A + vector B equals vector B + vector A 

Bullet point. group the addition of vectors in any order, where vector addition is **associative**.

 ( vector A + vector B ) + vector C equals vector A + ( vector B + vector C ) 

Bullet point. distribute scalar(s) across vector(s), where vector multiplication is **distributive**.
 
 
 ( alpha + beta ) vector A equals alpha vector A + beta vector A, 
 alpha ( vector A + vector B ) equals alpha vector A + alpha vector B.

2.2 Coordinate Systems and Vector Components

Coordinate Systems and Vector Components.

The graphic method of vector addition can be time-consuming, where we can instead describe a vector in terms of its components within a coordinate system. In a rectangular (**Cartesian**) xy -coordinate system in a plane, a point is described by a pair of coordinates (x, y) that "locate" the point. *Note we used this on the chessboard using letters and numbers for each cell.*

Vector components.

A vector vector A can be decomposed into its **vector components**, where each component is itself a vector. These vector components are constructed using the **unit vectors** i hat and j hat that mark a unit step in either the x or y -axis, respectively. Therefore, the vector vector A can be represented as

 
 vector A equals vector A _x + vector A _y, 
 equals A sub x i hat + A sub y j hat,
 

where the A sub x and A sub y represent the magnitude of the step along the respective Cartesian axis. Recall the chessboard where the start of the vector can be anywhere on the board. This means that the **component magnitudes** are measurements relative to where you start.

Let's define the starting location of vector vector A as a point ( x sub o, y sub o ), and the vector terminates at a point (x, y). Then, we can describe the vector as

 
 vector A equals vector A _x + vector A _y, 
 equals (x- x sub o ) i hat + (y- y sub o ) j hat.

**Example Problem**: Mouse pointer displacement.

The Problem.
A mouse pointer on the display monitor of a computer at its initial position is at point (6.0 cm, 1.6 cm ) with respect to the lower left-side corner. If you move the pointer to an icon located at point (2.0 cm, 4.5 cm ), what is the displacement vector of the pointer?

---

The Model.

We model the screen as a two-dimensional Cartesian coordinate system with the origin at the lower left corner of the monitor. The positive x -direction points to the right, and the positive y -direction points upward.

The displacement vector vector D is defined as the vector pointing from the **initial position** of the pointer to its **final position**. Its components are obtained by subtracting the initial coordinates from the final coordinates.

---

The Math.

Let the initial and final points point be

 
( x sub i, y sub i ) equals (6.0, 1.6) cm, 
 and 
( x sub f, y sub f ) equals (2.0, 4.5) cm.
 

The components of the displacement vector are

 
 D sub x equals x sub f - x sub i equals 2.0 - 6.0 equals -4.0 cm, 
 D sub y equals y sub f - y sub i equals 4.5 - 1.6 equals +2.9 cm.
 

Therefore, the displacement vector in unit-vector form is

 
 vector D equals D sub x i hat + D sub y j hat, 
 equals (-4.0 i hat + 2.9 j hat ) cm.
 

---

The Conclusion.

The mouse pointer’s displacement vector is vector D equals (-4.0 i hat + 2.9 j hat ) cm. This means the pointer moves 4.0 cm to the left and 2.9 cm upward from its initial position.

 **The Problem**
You move a mouse pointer on the display monitor from its initial position at point (6.0 cm, 1.6 cm ) to an icon located at point (2.0 cm, 4.5 cm ). What are the magnitude and direction of the displacement vector of the pointer?

---

The Model.

The Model.

We model the computer screen as a two-dimensional Cartesian coordinate system with the origin at the lower-left corner of the monitor. The positive x -direction points to the right, and the positive y -direction points upward.

The displacement vector points from the pointer’s initial position to its final position. Once that displacement is expressed in rectangular components, its magnitude is found from the component lengths, and its direction is determined by the orientation of the vector in the coordinate plane.

---

The Math.

The displacement vector vector D points from the initial position to the final position. Its components are found by subtraction:

 D sub x equals x sub f - x sub i, D sub y equals y sub f - y sub i. 

The initial and final positions of the mouse pointer are represented by the coordinate pairs

 
( x sub i, y sub i ) equals (6.0, 1.6) cm, 
( x sub f, y sub f ) equals (2.0, 4.5) cm.
 

The displacement components are found by subtracting the initial coordinates from the final coordinates along each axis.

 
 D sub x equals x sub f - x sub i equals 2.0 - 6.0 equals -4.0 cm, 
 D sub y equals y sub f - y sub i equals 4.5 - 1.6 equals +2.9 cm.
 

The magnitude of the displacement is determined from the Pythagorean relationship between the rectangular components.

 
D equals square root of D sub x to the power of 2 + D sub y to the power of 2 
 equals square root of (-4.0) squared + (2.9) squared cm 
 equals 4.9 cm.
 

The direction angle is first found from the ratio of the vertical component to the horizontal component.

 
 tan theta equals D sub y over D sub x equals +2.9 over -4.0 equals -0.725, 
 theta equals tan to the power of -1 (-0.725) equals -35.9 degrees.
 

Because D sub x 0, the displacement vector lies in Quadrant II. The direction angle measured counterclockwise from the positive x -axis is therefore

 
 theta _D equals theta + 180 degrees 
 equals -35.9 degrees + 180 degrees 
 equals 144.1 degrees.
 

Common Mistake.

 

A very common mistake when finding the direction of a displacement vector is to compute

 theta equals tan to the power of -1 ( D sub y over D sub x ) 

and **stop there**.

This inverse tangent only returns angles between -90 degrees and +90 degrees. It does **not** know which quadrant the vector lies in.

***What can go wrong***

Bullet point. If D sub x < 0, the vector is in Quadrant II or III.

Bullet point. If D sub y < 0, the vector is in Quadrant III or IV.

Bullet point. The raw tan to the power of -1 value must often be **adjusted by 180 degrees **.

In this problem:

 D sub x equals -4.0, D sub y equals +2.9 

so the displacement vector lies in **Quadrant II**, not Quadrant IV.
Failing to account for this would give the wrong direction angle.

Best practice.

Bullet point. **Always check the signs of D sub x and D sub y.**

Bullet point. Or, when using Python, use `np.arctan2(Dy, Dx)`, which automatically returns the correct quadrant.

 theta equals tan to the power of -1 ( D sub y over D sub x ) textbf{must never be used blindly.} 

 

---

The Conclusion.

The displacement vector has magnitude D equals 4.9 cm and direction theta _D equals 144.1 degrees (counterclockwise from the positive x -axis). It points into Quadrant II, consistent with D sub x equals -4.0 cm and D sub y equals +2.9 cm.

We've seen some properties of vectors from `Section 2.1.5 Properties of Vectors`, where there a few other properties not yet mentioned. A vector can be

 **Component Matching Rule**.

 

Vectors can only be added or subtracted by combining **matching components**.

Bullet point. i hat components combine **only** with i hat 

Bullet point. j hat components combine **only** with j hat 

Bullet point. k hat components combine **only** with k hat 

For example,

 (3 i hat + 2 j hat ) + (5 i hat - j hat ) equals 8 i hat + j hat, 

but expressions like

 3 i hat + 2 j hat + 5 k hat 

**cannot be simplified further** because none of the subscripts match.
If the subscripts do not match, the components represent **different directions** and cannot be combined.
 

Vector addition by components is accomplished as follows:

 
 vector R equals vector A + vector B, 
 equals ( A sub x + B sub x ) i hat + ( A sub y + B sub y ) j hat + ( A sub z + B sub z ) k hat, 
 equals R sub x i hat + R sub y j hat + R sub z k hat.

 vector F _R equals vector F _1 + vector F _2 + ldots + vector F _N equals sum sub n equals 1 to the power of N vector F _n,

The Model.

We model each displacement as a two-dimensional vector in the x - y plane. Each vector is described by a magnitude and a direction angle, so each one can be resolved into horizontal and vertical components. The Math.

The Model.

We model the convoy’s velocity as a three-dimensional vector with east, north, and upward components. The direction of motion is represented by a unit vector parallel to the velocity vector.

A unit vector describes direction only and has no physical units. To find the unit vector, the velocity vector is scaled so that its magnitude becomes one while its direction remains unchanged.

---

The Math.

The unit vector in the direction of motion is found by dividing the velocity vector by its magnitude.

 v hat equals vector v over | vector v |. 

The magnitude of the velocity vector is determined from its three rectangular components.

 
| vector v | equals square root of v sub x to the power of 2 + v sub y to the power of 2 + v sub z to the power of 2

 v hat equals 4.0 i hat + 3.0 j hat + 0.10 k hat over 5.0

2.4 Products of Vectors

Products of Vectors.

A vector can be multiplied by another vector, **but may not be divided by another vector**. There are two kinds of vector products:

Bullet point. scalar multiplication (dot product), or

Bullet point. vector multiplication (cross product).

As the names imply, the result of the multiplication produces either a scalar or a vector.

The Dot Product.

The **scalar product** of two vectors is denoted using dot (` dot `) symbol instead of the normal times (` times `) symbol. The scalar product of vectors vector A and vector B is defined by

 
 vector A dot vector B equals AB cos{ phi },
 

where the angle phi represents an angle between the two vectors.

Note.

In LaTeX, there are two versions of `phi`, which can include phi (` phi `) or phi (` phi `). Both versions mean the same thing, but you need to be consistent. 
 

In the definition of the dot product, the direction of the angle phi does not matter due to the property of cos{ phi } equals cos{- phi } (i.e., cosine is an even function). The dot product is a negative number in Quadrant II because cos{ phi } 0, when 0 < phi < pi /2.

When two vectors are parallel, the angle phi equals 0 and vector A dot vector B equals AB cos{0} equals AB.

What happens when the vectors are antiparallel or perpendicular?.

Bullet point. For antiparallel vectors, vector A dot vector B equals -AB.

Bullet point. for perpendicular (or orthogonal) vectors, vector A dot vector B equals 0.

The scalar product of a vector with itself is the square of its magnitude:

 
 vector A to the power of 2 equiv vector A dot vector A equals AA cos{0} equals A squared.
 

Checkpoint.

 

The dot product of two vectors is negative.

Is the angle between the vectors less than, equal to, or greater than 90 degrees?
 

Rules using unit vectors.

In the Cartesian coordinate system, scalar products of a unit vector with another (different) unit vector vanish because these unit vectors are **orthogonal**:

 
 i hat dot j hat equals cos{ ( pi over 2 )} equals 0, 
 i hat dot k hat equals cos{ ( pi over 2 )} equals 0, 
 k hat dot j hat equals cos{ ( pi over 2 )} equals 0.
 

We often take advantage of the fact that the magnitudes of all unit vectors are one:

 
| i hat | equals i hat dot hat {i} equals i squared equals 1, 
| j hat | equals j hat dot hat {j} equals j squared equals 1, 
| k hat | equals k hat dot hat {k} equals k squared equals 1. 
 

The scalar product is also interpreted as the *projection* of one vector onto the *direction* of the other vector (i.e., projection A sub || onto the direction of vector B ):

 
 vector A dot vector B equals AB cos{ phi }, 
 equals B(A cos{ phi }) equals BA sub ||, 
 equals A(B cos{ phi }) equals AB sub ||.
 

Recall the definitions of the vector components A sub x and A sub y. We can define these quantities through the dot product with the appropriate unit vector. For example, using the vector vector A equals A sub x i hat + A sub y j hat:

 
 vector A dot i hat equals A sub x ( i hat dot i hat ) + A sub y ( i hat dot j hat ) equals A sub x cos(0) + A sub y cos( pi /2) equals A sub x, 
 vector A dot j hat equals A sub x ( j hat dot i hat ) + A sub y ( j hat dot j hat ) equals A sub x cos( pi /2) + A sub y cos(0) equals A sub y.
 

Scalar multiplication follows the previous properties of vector operation, where they are:

Bullet point. commutative; vector A dot vector B equals vector B dot vector A,

Bullet point. distributive; vector A dot ( vector B + vector C ) equals vector A dot vector B + vector A dot vector C.

We can compute the scalar products of two vectors using the distributive property:

 
 vector A dot vector B equals ( A sub x i hat + A sub y j hat + A sub z k hat ) dot ( B sub x i hat + B sub y j hat + B sub z k hat ) 
 equals A sub x B sub x i hat dot i hat + A sub x B sub y i hat dot j hat + A sub x B sub z i hat dot k hat 
 + A sub y B sub x j hat dot i hat + A sub y B sub y j hat dot j hat + A sub y B sub z j hat dot k hat 
 + A sub z B sub x k hat dot i hat + A sub z B sub y k hat dot j hat + A sub z B sub z k hat dot k hat.
 

Applying our rules for the dot products of unit vectors, the above expression simplifies quickly to 

 
 vector A dot vector B equals A sub x B sub x + A sub yB _y + A sub zB _z
 

If we know the magnitudes ( A and B ) and the vector components of each vector, then we can solve for the angle phi between them:

 
 cos{ phi } equals vector A dot vector B over AB equals A sub x B sub x + A sub yB _y + A sub zB _z over AB, 
 phi equals cos to the power of -1 ( A sub x B sub x + A sub yB _y + A sub zB _z over AB ).

Since the radial vector and the applied force lie in the plane of the wrench, the torque vector must point perpendicular to that plane. The Math.

The magnitude of the torque produced by a force applied at an angle phi relative to the radial direction is

 tau equals RF sin phi.

 tau equals (0.25 meters )(20.0 newtons ) sin 40 degrees equals 3.21 newtons dot m.

 tau equals (0.25 meters )(20.0 newtons ) sin 45 degrees equals 3.53 newtons dot m. 

For the orientation shown in part (b), the right-hand rule gives a torque in the negative z -direction, which is into the page.

 tau sub max equals RF equals (0.25 meters )(20.0 newtons ) equals 5.00 newtons dot m. 

---

The Conclusion.

For phi equals 40 degrees, the torque has magnitude

 tau equals 3.21 newtons dot m 

and points in the positive z -direction, out of the page. For phi equals 45 degrees, the torque has magnitude

 tau equals 3.53 newtons dot m 

and points in the negative z -direction, into the page. The maximum possible torque occurs when phi equals 90 degrees, giving

The torque increases as the force becomes more perpendicular to the wrench handle, and its direction is set by the right-hand rule.
