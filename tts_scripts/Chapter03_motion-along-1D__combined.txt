3.1 Position, Displacement, and Average Velocity

Motion along 1D.

Chapter roadmap.

 

This chapter introduces one-dimensional kinematics. We describe motion without yet explaining what causes it, so the object is modeled as a particle moving along one straight axis.

As you read, focus on three questions:

Item 1. Can I define a coordinate axis and use algebraic signs to represent direction?

Item 2. Can I distinguish position, displacement, velocity, and acceleration?

Item 3. Can I use graphs and equations to describe how motion changes with time?

These ideas provide the foundation for describing motion in two and three dimensions in the next chapter.
 

Position, Displacement, and Average Velocity.

Position.

To describe the motion of an object, must first locate it using its **position** x (i.e., *where it is at any particular time.*). More precisely, we need to specify its position relative to a convenient frame of reference.

A **frame of reference** is an arbitrary set of axes from which the position (and motion) of an object are described. We often describe the position of an object relative to the "stationary" Earth or objects on the Earth. For example,

Bullet point. a rocket could relate its position relative to the Earth as a whole,

Bullet point. a cyclist's position could relate to the nearby buildings.

It is not necessary for the reference to be stationary. For example, to describe a position of a person in an airplane, we use the airplane as the reference frame even though it is moving through the air.

Typically, we use the variable x when discussing 1-D motion (in general), where we might use the variable y when discussing vertical motion.

Displacement.

If an object moves relative to a frame of reference, then the object's position changes (i.e., displacement). The word *displacement* implies that an object has moved. Recall from Chapter 2, displacement is a vector with magnitude and direction. In 1-D, the direction is simply represented as a positive ( + ) or negative ( - ) relative to the reference. For example,

Bullet point. moving 2 meters to the **right** is indicated by a displacement of +2 meters,

Bullet point. moving 4 meters to the **left** is indicated by a displacement of -4 meters.

**Displacement** change in x is the change in position of an object:

 
 change in x equals x sub f - x sub o,
 

where x sub f is the final position and x sub o is the initial position.

Note.

We use the uppercase Greek letter delta ( change in ) to mean "change in" a variable. Thus, change in x means *change in position*. We always solve for displacement with the difference of x sub o **from** x sub f.

Objects in motion can have a series of displacements, where we define **total displacement** change in x sub Tot as the *sum of the individual displacements* (recall how we summed multiple vectors to find the resultant), and express this mathematically as,

 
 change in x sub Tot equals sum sub i equals 1 to the power of N x sub i -x sub i-1, 
 equals sum sub i equals 1 to the power of N change in x sub i,
 

where change in x sub i are the individual displacements. In the earlier example, we had change in x sub 1 equals 2 meters and change in x sub 2 equals -4 meters so that change in x sub Tot equals -2 meters. But we need to work out the individual x sub i. Here's what we know,

 
 change in x sub Tot equals change in x sub 2 + change in x sub 1, 
 equals ( x sub 2 - x sub 1 ) + ( x sub 1 - x sub o ), 
-2 meters equals -4 meters + 2 meters.
 

This means we have

 
 x sub 2 - x sub 1 equals -4 meters, 
 x sub 1 - x sub o equals 2 meters.
 

*What is x sub o?* -- It's the initial reference or where we started before moving at all (i.e., the origin). In this case, x sub o equals 0, which means we now know 

Bullet point. x sub o equals 0 

Bullet point. x sub 1 - 0 equals 2 meters arrow x sub 1 equals 2 meters.

Bullet point. x sub 2 - 2 meters equals -4 meters arrow x sub 2 equals -2 meters 

Thus, the total displacement is given by

 
 change in x sub 1 equals x sub 1 - x sub o equals 2-0 equals 2 meters, 
 change in x sub 2 equals x sub 2 - x sub 1 equals -2 - 2 equals -4 meters, 
 change in x sub Tot equals change in x sub 2 + change in x sub 1 equals -4 + 2 equals -2 meters.
 

The total displacement is -2 meters along the x -axis, or vector D equals -2 i hat m. The above process can be represented in vectors by

 
 vector x _1 equals change in x sub 1 i hat equals 2 i hat m, 
 vector x _2 equals change in x sub 2 i hat equals -4 i hat m,

The magnitude of the displacement is always positive, |D| equals sqrt{ vector D dot vector D }. In this case, we can find that |D| equals 2 meters.

Average Velocity.

To calculate how fast something is moving, we must introduce the time variable t. Similar to the displacement change in x, there is a time between two points, which is called the **elapsed time** change in t equals t sub f - t sub o.

Checkpoint.

 

Can the average velocity be zero even when the distance traveled is not zero?

Explain using displacement.
 

If x sub f and x sub o are the positions of an object at times t sub f and t sub o, respectively, then the **average velocity** bar{v} is

 
 bar{v} equals Displacement between two points over Time interval between two points, 
 equals change in x over change in t equals x sub f - x sub o over t sub f - t sub o.
 

Note.

The average velocity is a vector and can be negative, when x sub f < x sub o. This means that the average velocity can be in the opposite direction as the positive reference direction.
 

**Example Problem**: Delivering Flyers.

The Problem.
Jill sets out from her home to deliver flyers for her yard sale, traveling due east along her street lined with houses. At 0.5 km and 9 min later she runs out of flyers and has to retrace her steps back to her house to get more. This takes an additional 9 min. After picking up more flyers, she sets out again on the same path, continuing where she left off, and ends up 1.0 km from her house. This third leg of her trip takes 15 min. At this point she turns back toward her house, heading west. After 1.75 km and 25 min she stops to rest.
a. What is Jill’s total displacement to the point where she stops to rest? 
b. What is the magnitude of the final displacement? 
c. What is the average velocity during her entire trip? 
d. What is the total distance traveled? 
e. Make a graph of position versus time.

---

The Model.

Jill’s motion is one-dimensional along an east-west street. We choose east as the positive x -direction, west as the negative x -direction, and Jill’s home as the origin. The trip is broken into straight-line segments, so the net displacement depends only on the starting and ending positions, while the total distance depends on the length of every segment traveled.

---

The Math.

We choose Jill’s home as x sub o equals 0 and reconstruct her position at the end of each leg. After the first leg, she is at x sub 1 equals +0.5 km after 9 min. After returning home, she is at x sub 2 equals 0 after 18 min. After the third leg, she is at x sub 3 equals +1.0 km after 33 min. During the final leg, Jill travels 1.75 km west from x sub 3 equals +1.0 km, so her final position is given by

 x sub 4 equals 1.0 km - 1.75 km equals -0.75 km. 

The signed displacement during each segment is the change in position for that segment, which gives

 
 change in x sub 1 equals +0.5 km, 
 change in x sub 2 equals -0.5 km, 
 change in x sub 3 equals +1.0 km, 
 change in x sub 4 equals -1.75 km.
 

**(a)** The total displacement is the change from the initial position to the final position, which is given by

 change in x_ total equals x sub 4 - x sub o equals -0.75 km. 

**(b)** The magnitude of the final displacement is the absolute value of the total displacement, which is

 | change in x_ total | equals 0.75 km. 

**(c)** The total elapsed time is the sum of the four time intervals, which gives

 change in t_ total equals 9 min +9 min +15 min +25 min equals 58 min. 

The average velocity over the entire trip is the total displacement divided by the total elapsed time, which gives

 
 bar{v} equals change in x_ total over change in t_ total, 
 equals -0.75 km over 58 min, 
 equals -0.013 km/min.
 

**(d)** The total distance traveled is the sum of the magnitudes of the segment displacements, which gives

 
d_ total equals | change in x sub 1 | + | change in x sub 2 | + | change in x sub 3 | + | change in x sub 4 |, 
 equals 0.5 km + 0.5 km + 1.0 km + 1.75 km,

---

The Conclusion.

Jill’s final displacement is -0.75 km, so she ends 0.75 km west of her house. Her average velocity is -0.013 km/min, where the negative sign shows that her net motion is westward. Her total distance traveled is 3.75 km, which is larger than the magnitude of her displacement because she reverses direction more than once.

3.2 Instantaneous Velocity and Speed

Instantaneous Velocity and Speed.

Instantaneous Velocity.

The quantity that tells us how fast an object is moving anywhere along its path is the **instantaneous velocity**, or simply *velocity*. It is the average velocity between two discrete points on the path.

Suppose we know the position x of an object at any time t, then we would know the continuous function x(t). We can express the average velocity bar{v} by

 bar{v} equals x( t sub 2 )-x( t sub 1 ) over t sub 2 - t sub 1 equals change in x over change in t. 

To find the instantaneous velocity at any position, we let t sub 1 arrow t and t sub 2 arrow t + change in t. Then we substitute into our expression for the average velocity and define v(t) by,

 
v(t) equals the limit of sub change in t arrow 0 x(t+ change in t) - x(t) over change in t equals dx(t) over dt.
 

We now define the instantaneous velocity of an object is the limit of the average velocity bar{v} as the elapsed time change in t approaches zero, or the derivative of x with respect to t:

 
v(t) equals d over dt x(t).
 

Instantaneous velocity is a vector with dimension of L/T. Since the definition of average velocity is written in terms of the change in position change in x over a specific time interval change in t, we also refer to the velocity as the *rate of change of the position function*. 

The **rate of change** is a measure of how fast a function is changing at a time t, or the slope of the line that is tangent to the curve at t. The displacement at the initial time t sub o is zero (i.e., change in x equals 0 ), therefore the velocity will also be zero and the slope will be *flat*.

On a position-versus-time graph, what does a horizontal tangent line mean about the velocity at that instant?
 

At other times ( t sub 1, t sub 2, dots, t sub N ), the velocity is not zero (unless the position never changes) because the slope would be positive or negative. If the function x(t) had a minimum, then the slope would also be zero (i.e., v(t) equals 0 ). Thus, the zeros of the velocity function give the *minimum* and *maximum* of the position function.

3.3 Average and Instantaneous Acceleration

Average and Instantaneous Acceleration.

Average Acceleration.

The **average acceleration** bar{a} is the *rate of change* for the velocity v:

 
 bar{a} equals change in v over change in t equals v sub f - v sub o over t sub f - t sub o,
 

where t is time.

The SI units for acceleration are meters per second squared (or meters per second per second) and abbreviated as meters per second squared. This means how much the velocity has changed every second, where the velocity can change in either *magnitude* or *direction* due to it being a vector. For example,
a runner traveling at 10 kilometers per hour due east slows to a stop reverses direction, and continues to run 10 kilometers per hour due west.

Before turning around, the runner had one average acceleration, then a different average acceleration afterwards. This is shown mathematically as,

 
 bar{a} equals 
 - v sub o over t sub m - t sub o equals -10 over change in t sub 1, from start to turning around at t sub m 
 v sub f over t sub f - t sub m equals 10 over change in t sub 2, from turning around onward until t sub f.
 
 

The *magnitude* of the velocity is the same in both directions, however the direction is different. Acceleration is a *vector* in the same direction as the *change in velocity* change in v. Acceleration is a change in *speed or direction*, or both.

Note.

Although acceleration is in the direction of the change in velocity, it is not always in the direction of motion. When an object slows down, its acceleration is opposite to the direction of its motion.
 

The term *deceleration* can cause confusion because it is **not** a vector and it does not point to a specific direction with respect to a specific direction. 

We can say the runner was decelerating before coming to a stop and accelerating afterward, but we shouldn't include the coordinate system unit vector ( i hat or - i hat ) in our analysis. Otherwise the runner always has a negative acceleration, in contrast to our intuition. Instead of using the term deceleration, we describe the motion more accurately with a positive or negative acceleration relative to the coordinate system. 

If an object has a velocity in the positive direction with respect to the origin and it acquires a constant negative acceleration, the object eventually comes to rest and reverses direction (i.e., our runner in change in t sub 1 ). Eventually, the object passes through the origin going in the opposite direction (i.e., our runner in change in t sub 2 ). 

Checkpoint.

 

An object has v equals +8 meters per second and a equals -2 meters per second squared.

Is it moving in the positive or negative direction? Is it speeding up or slowing down?
 

The sign of acceleration tells us the direction of the change in velocity, not whether the object is speeding up or slowing down. To decide whether the speed is increasing or decreasing, we compare the signs of velocity and acceleration. If v and a have the same sign, the object speeds up. If v and a have opposite signs, the object slows down.

Calculus Note: Derivatives, Extrema, and Evolution.

 
 

Finding Extrema by Setting the Derivative to Zero.

One of the most powerful and general uses of calculus is identifying where a quantity reaches a **maximum or minimum**. 
Given a function f(x), extrema occur at **critical points**, which satisfy

 df over dx equals 0 

(or where the derivative is undefined).

This works because the derivative represents the *rate of change* of the function. At a maximum or minimum, the function momentarily stops increasing or decreasing, so its slope is zero.

Examples.

Bullet point. In kinematics, setting v(t) equals dx over dt equals 0 finds when an object momentarily stops or turns around.

Bullet point. In optimization, setting dE over dx equals 0 finds stable equilibrium configurations.

Bullet point. In thermodynamics, extrema of entropy or energy determine equilibrium states.

This method applies to **any differentiable function**, not just position or velocity.

---

Using Derivatives to Evolve a System.

Derivatives do more than identify special points. They describe how systems *change in time*. Many physical laws are written as **differential equations**, which specify how a quantity evolves:

 dy over dt equals f(y,t) 

Here, the derivative tells us how the system changes at each instant. Solving the differential equation allows us to predict the system’s future behavior.

Examples.

Bullet point. Newton’s Second Law:

 m dv over dt equals F(x,v,t) 

 determines how velocity evolves from forces.

Bullet point. Radioactive decay:

 dN over dt equals - lambda N 

 describes how a quantity decreases over time.

Bullet point. Population growth, electrical circuits, orbital motion, and climate models are all governed by differential equations.

---

Big Picture.

Bullet point. **Setting derivatives equal to zero** finds *where something stops changing* (extrema, turning points, equilibrium).

Bullet point. **Using derivatives in equations** tells us *how something changes* (motion, growth, decay, evolution).

Together, these ideas form the mathematical backbone of physics, engineering, and applied science.

3.4 Motion with Constant Acceleration

Motion with Constant Acceleration.

Before using the constant-acceleration equations, we need to decide whether this model applies. These equations are powerful, but they only describe motion where the acceleration is constant over the interval being analyzed.

Checkpoint.

 

A car accelerates from rest, then later brakes to a stop.

Should the entire trip be modeled with one constant acceleration, or should it be split into separate intervals?
 

Choosing a One-Dimensional Motion Model.

 

Use the following questions before choosing an equation.

Item 1. **Is the motion along one straight axis?** 
 If yes, the motion can be described with one-dimensional position, velocity, and acceleration.

Item 2. **Is the acceleration constant over the interval?** 
 If yes, the constant-acceleration equations can be used. If no, use graphs, calculus, or split the motion into intervals where the acceleration is approximately constant.

Item 3. **Are the known and unknown quantities among x, x sub o, v, v sub o, a, and t?** 
 If yes, choose an equation that contains the unknown and the given quantities.

Item 4. **Does the sign of the answer make physical sense?** 
 Check whether the object is moving in the expected direction, speeding up or slowing down appropriately, and whether any time value is physically meaningful.
 

**Khan Academy**.

 

 
 

Notation.

To make things simpler, we introduce some **conventions in notation**. One simplification is taking t sub o equals 0, which is the point in time when you begin to measure. Time exists before this point, but until "you get your Delorean to 88 mph", then it doesn't make sense to include the past.

The elapsed time goes from change in t equals t sub f - t sub o to change in t equals t sub f. We don't need the subscript f anymore. So, the elapsed time is change in t equals t. We can drop the subscript f from the change in x and change in v as well. In our simplified notation we have

 
 change in t equals t, 
 change in x equals x- x sub o, 
 change in v equals v- v sub o,
 

where the subscript o denotes an initial value and the *absence of a subscript* indicates the final value of the variable.

For now, we will also make the assumption that the acceleration is *constant*. As a result, the average and instantaneous acceleration are equal, or

 bar{a} equals a equals constant. 

In many situations in this course, the acceleration is constant. When it isn't (e.g., a car accelerating to top speed, then braking to a stop), the motion will be considered in separate parts (like with the runner) and each part has its own constant acceleration.

Displacement and Position from Velocity.

To get our first two equations, we start with the definition of average velocity:

 bar{v} equals change in x over change in t, 

and substitute the simplified notation to get

 bar{v} equals x- x sub o over t. 

Solving for x gives

 
x equals x sub o + bar{v}t,
 

where the arithmetic average velocity is

 
 bar{v} equals v sub o + v over 2.
 

This version of bar{v} reflects that when **acceleration is constant**, then bar{v} is the simple average of the initial and final velocities.

Solving for Final Velocity from Acceleration and Time.

We can derive another useful equation by manipulating the definition of acceleration:

 a equals change in v over change in t. 

By substituting the simplified notation for change in v and change in t, we have

 
a equals v- v sub o over t ( constant a).
 

Solving for v yields

 
v equals v sub o + at ( constant a).
 

The above equation gives us insight into relationships among velocity, acceleration, and time. We can see that

Bullet point. Final velocity depends on both acceleration and time

Bullet point. For zero acceleration, then the initial and final velocities are equal (i.e., v equals v sub o )

Bullet point. If a<0, then v< v sub o.

These relationships fit our intuition, which can be a good sign.

The Problem.

 **Time-based form**

 a equals v - v sub o over t 

Bullet point. If the change in velocity (v - v sub o ) is **small** and the time (t) is **finite**, the acceleration is small.

Bullet point. If (v equals v sub o ), then (a equals 0): there is no acceleration.

Bullet point. But if we try to change velocity by a **finite amount** in an **extremely short time** ((t arrow 0)), the acceleration becomes very large.

This situation does **not** represent realistic motion. It corresponds to an instantaneous jump in velocity, which would require an infinite force.

Displacement-based form.

 a equals v squared - v sub o to the power of 2 over 2(x - x sub o ) 

Bullet point. If the velocity change is small and the displacement is finite, the acceleration is small.

Bullet point. If (v equals v sub o ), the numerator is zero and (a equals 0).

Bullet point. If a finite velocity change occurs over **almost no distance**, the acceleration again becomes very large.

This describes another unphysical situation: a sharp change in motion over essentially zero distance.

How calculus resolves the issue.

When both the change in velocity *and* the time (or displacement) become small together, these expressions take the indeterminate form (0/0). In that limit, acceleration must be defined using a derivative:

 a equals the limit of sub change in t arrow 0 change in v over change in t equals dv over dt. 

This definition ensures that acceleration remains **finite** for smooth, realistic motion.

Key takeaway.

Bullet point. Very large accelerations arise when velocity changes too abruptly.

Bullet point. Real objects change velocity smoothly, not instantaneously.

Bullet point. Calculus replaces finite differences with derivatives to correctly describe motion at an instant.

This is why sharp corners on velocity graphs imply infinite acceleration and why real motion curves are smooth.

3.5 Free Fall

Free Fall.

Gravity.

Until Galileo Galilei showed otherwise, people believed that a heavier object has a greater acceleration in a free fall. We know now that this is not the case. 

Bullet point. In the absence of air resistance, heavy objects arrive at the ground at the same time as lighter objects when dropped from the *same* height.

**BBC**.

 

 
 

In the real world, air resistance can cause a lighter object to fall slower than a heavier object of the same size. A tennis ball reaches the ground after a baseball dropped at the same time, although the difference is not large. Air resistance opposes the motion of an object through the air and friction between objects also opposes motion between them.

**Free fall** is when an object falls *without air resistance* or *friction*. The force of gravity causes objects to fall toward the center of the Earth, where this acceleration is also called the **acceleration due to gravity**. 

Near Earth's surface (or for small changes in altitude) the acceleration due to gravity is constant, which means we can apply the kinematic equations to any falling object (where air resistance and friction are negligible), including spherical cows.

Acceleration due to gravity is given its own symbol g, where it is nearly constant at any location on Earth's surface with the average value

 g equals 9.81 meters per second squared ( or 32.2 ft/s squared ). 

The value of g can vary from 9.78 - 9.83 meters per second squared depending on latitude, altitude, underlying geological formations, and local topography. Here we use g equals 9.81 meters per second squared unless otherwise specified.

Checkpoint.

 

A ball is thrown straight upward. At the highest point, its velocity is momentarily zero.

What is its acceleration at that instant?
 

The direction of acceleration due to gravity g is defined to be downward (i.e., toward Earth's center). Its direction defines what we call vertical.

Note.

The acceleration a in the kinematic equations has the value +g or -g depending on how we define our coordinate system. If we define the

Bullet point. upward direction as positive, then a equals -g equals -9.81 meters per second squared.

Bullet point. downward direction as positive, then a equals g equals 9.81 meters per second squared.
 

One-Dimensional Motion Involving Gravity.

Consider vertical (up-and-down) motion with no air resistance or friction, where these assumptions mean the velocity is also vertical. There are some statements about the initial velocity of an object as it enters or leaves free fall. The object is in free fall after it has left contact with whatever held or threw it. 

Bullet point. If an object is dropped, we know the initial velocity is zero when in free fall (i.e., v sub o equals 0 ).

Bullet point. If the object is thrown, it has the same speed in free fall as it did before it was released (i.e., v sub o is defined at release).

When in free fall, the motion is 1D and has constant acceleration of magnitude g. When the object comes in contact with the ground (or any other object), it is no longer in free fall (i.e., a is not equal to g ). 

We represent the vertical displacement with the symbol y and write the following **kinematic equations for objects in free fall**. We assume that the positive direction is upward, which gives

 
v equals v sub o - gt, 
y equals y sub o + v sub o t - 1 over 2 gt squared, 
v squared equals v sub o to the power of 2 -2g(y- y sub o ).
 

When solving free fall problems, its helpful to follow this strategy:

Item 1. Decide on the sign of g (i.e., is positive upward or downward). In some problems, it may be useful to have +g indicating the positive direction is downward.

Item 2. **DRAW A SKETCH** of the problem. Visualizing the problem can be a useful first step. *Don't worry about artistic quality.*

Item 3. Identify the knowns and unknowns from the problem description.

Item 4. Match the kinematic equations with the knowns and unknowns.

3.6 Finding Velocity and Displacement from Acceleration

Finding Velocity and Displacement from Acceleration.

Kinematic Equations from Integral Calculus.

In later chapters, we'll start with a force that depends on the acceleration a. There is some insight into why calculus is useful to determine (or remember) the kinematic equations.

Let's begin with a particle with an acceleration a(t), which we can express as in differential form by

 a(t) equals d over dt v(t), 

in terms of the the velocity function. One way to solve a differential equation is to take the indefinite integral of both sides, where we get

 integral a(t) dt + C sub 1 equals integral d over dt v(t) dt, 

and C sub 1 represents a constant of integration. 

Note.

The integral of the derivative of a function is simply the function. For example,

 integral d over dx f(x)dx equals f(x). 

The integral is also called the **anti-derivative** because it is like an inverse operation of the derivative. This is similar to how square root of x squared equals x, *if we take only the positive root.*
 

Using the antiderivative property from calculus, we have

 
 integral a(t)dt + C sub 1 equals v(t).
 

We can employ the same procedure to write the velocity function in terms of the position function, as

 v(t) equals d over dt x(t), 

and with the integral, we have

 
 integral v(t) dt + C sub 2 equals x(t),
 

where C sub 2 is a second constant of integration.

Checkpoint.

 

If acceleration is the slope of the velocity graph, what does the area under an acceleration-versus-time graph represent?
 

Using these integrals, we can derive the kinematic equations. Since a(t) can be any function, let's assume that a(t) equals at to the power of 0 equals a equals constant. Then we can evaluate the velocity function as

 
v(t) equals integral adt + C sub 1, 
 equals v sub o + at.
 

where C sub 1 equals v sub o equals v(0). Then we can substitute into the integral to get the position function, or

 
x(t) equals integral ( v sub o + at)dt + C sub 2, 
 equals x sub o + v sub ot + 1 over 2 at squared,
 

where C sub 2 equals x sub o equals x(0).

**Example Problem**: Motion of a Motorboat.

The Problem.

---

The Model.

The motorboat moves in one dimension along the direction of its initial motion. We choose the initial position as the origin and measure time from the instant the deceleration begins.

---

The Math.

**(a)** Velocity is found by integrating the acceleration function with respect to time, which gives

 
v(t) equals integral a(t) dt,

The integration constant is determined by the initial velocity v(0) equals 5.0 meters per second, which gives C sub 1 equals 5.0 meters per second. The velocity function is therefore

 v(t) equals (5.0- 1 over 8 t squared ) meters per second. 

**(b)** The stopping time occurs when the velocity reaches zero, so the velocity function gives

 0 equals 5.0 - 1 over 8 t squared. 

Solving this equation for the positive time gives

 
t squared equals 40, 
t equals 6.3 s.
 

**(c)** Position is found by integrating the velocity function with respect to time, which gives

 
x(t) equals integral v(t) dt, 
 equals integral (5.0- 1 over 8 t squared )dt, 
 equals 5.0t - 1 over 24 t cubed + C sub 2.
 

The initial position is chosen to be x(0) equals 0, so C sub 2 equals 0. The position function is therefore

 x(t) equals (5.0t- 1 over 24 t cubed ) m. 

**(d)** The displacement while the boat slows to rest is found by evaluating the position function at t equals 6.3 s, which gives

 
x(6.3 s ) equals 5.0(6.3) - 1 over 24 (6.3) cubed,

**(e)** The velocity and position graphs are generated from the functions derived above. The velocity graph decreases to zero at t equals 6.3 s, and the position graph reaches its maximum value at that same time.

---

The Conclusion.

The motorboat’s velocity function is v(t) equals (5.0- 1 over 8 t squared ) meters per second, and its position function is x(t) equals (5.0t- 1 over 24 t cubed ) m.
